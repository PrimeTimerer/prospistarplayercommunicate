# Changelog

## 2.7.10-preview — 2026-09-13

- Initial MIT public-source snapshot based on the 2.7.9 engine.
- Excluded private history, profiles, saves, original OCR, conversations and logs.
- Replaced extracted fixtures and personal story-reference material with synthetic
  examples. Kept existing storage/routes and opt-in import IDs compatible.
- Added isolated tests, public-tree auditing, setup/build documentation and CI.
- Local installed/private 2.7.9 is not overwritten by this source publication.

## Included engine baseline

- Gemini/local/deterministic provider paths, independent generation/review budgets,
  structured JSON semantic review and preservation of prior results on failure.
- Community/article/narrative workspaces, connected memory and date-based recaps.
- Read-only verified save parsing, player/world isolation and historical archives.

Automatic test success does not guarantee arbitrary live provider output or every
game build. Private development chronology is intentionally not distributed.
