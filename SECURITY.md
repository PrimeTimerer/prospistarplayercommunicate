# Security and private data

Do not post API keys, saves, raw logs, user profile paths, personal chats or
original screenshots in public issues. Revoke a leaked key at its provider;
deleting a public commit does not guarantee removal from caches or clones.

Use this repository's **Security → Report a vulnerability** for sensitive reports
when available. If private reporting is unavailable, open only a non-sensitive
request for a private reporting channel; do not include the vulnerability payload
or credentials. No response-time guarantee is made for this community preview.
